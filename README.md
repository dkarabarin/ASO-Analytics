## 📝 Описание

**ASO Analytics Service** — веб-сервис для анализа ASO-данных (App Store Optimization) приложения Sound Amplifier. Сервис полностью воспроизводит функциональность Jupyter Notebook и дополняет её:

- 🖥️ **веб-интерфейсом** с пошаговой навигацией;
- 🤖 **LLM-аналитикой** на основе методологии ASO;
- 📊 **интерактивными графиками** для каждого этапа анализа;
- 🔄 **API для автоматизации** всех этапов;
- 📄 **генерацией итоговых отчётов** в формате JSON.

## 🎯 Основные возможности

### 1. 📁 Загрузка и предобработка данных
- Парсинг Excel-файлов (2024, 2025, 2026)
- Дедупликация записей
- Создание временных и лаговых признаков
- Сохранение в CSV и Pickle

### 2. 📊 Разведочный анализ (EDA)
- Общая статистика данных
- Распределение мотива и позиций
- Топ-20 ключевых слов
- Корреляционный анализ
- Анализ сценариев изменения мотива
- **8 видов графиков** визуализации

### 3. 📂 Кластеризация
- Бизнес-кластеризация по позициям (top10, top50, above50)
- Кластеризация по объёму мотива (zero, low, medium, high)
- Выявление якорных слов
- Визуализация кластеров

### 4. 🤖 ML-моделирование
- **XGBoost** с оптимизацией гиперпараметров (Optuna)
- **LightGBM** с оптимизацией гиперпараметров (Optuna)
- Сравнение с базовыми моделями (Linear Regression, Random Forest)
- Анализ важности признаков
- Кросс-валидация по времени

### 5. 📐 Статистические тесты
- **H1** — корреляция похожих запросов (> 0.7)
- **H3** — эффективность сценариев (критерий Краскела — Уоллиса)
- **H4** — влияние фризов (парный t-тест)
- **H5** — влияние мотива (корреляция Пирсона / Спирмена)

### 6. 📄 Генерация отчётов
- Сводная статистика
- Результаты кластеризации
- Результаты ML-моделей
- Результаты проверки гипотез
- Практические рекомендации
- Экспорт в JSON

### 7. 💬 LLM-ассистент
- Анализ данных на основе методологии ASO
- Генерация гипотез
- Предложение стратегий продвижения
- Объяснение кластеров и правил
- Свободный диалог с сохранением контекста

## 📦 Установка

### Требования
- Python 3.11+
- pip
- (опционально) Ollama для LLM

### Шаг 1. Клонирование репозитория

```bash
git clone <repository-url>
cd app_web
```

### Шаг 2. Создание виртуального окружения

```bash
python -m venv venv
source venv/bin/activate   # Linux/Mac
venv\Scripts\activate      # Windows
```

### Шаг 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### Шаг 4. Подготовка данных

```bash
# Создайте папку data и поместите в неё Excel-файлы
mkdir data

# Скопируйте файлы:
# data/Sound Amplifier_2024.xlsx
# data/Sound Amplifier_2025.xlsx
# data/Sound Amplifier_2026.xlsx
```

## 📖 Использование

### 1. Через веб-интерфейс

1. Откройте http://localhost:8000
2. Нажмите «Выполнить все этапы» либо пройдите по шагам последовательно:
   - Шаг 1 — Загрузка данных
   - Шаг 2 — EDA
   - Шаг 3 — Кластеризация
   - Шаг 4 — ML-обучение
   - Шаг 5 — Статистические тесты
   - Шаг 6 — Отчёт
   - Шаг 7 — LLM-чат

### 2. Через API (cURL)

```bash
# 1. Загрузка данных
curl -X POST http://localhost:8000/api/data/load

# 2. EDA
curl -X POST http://localhost:8000/api/eda/run

# 3. Кластеризация
curl -X POST http://localhost:8000/api/clustering/run

# 4. ML-обучение
curl -X POST http://localhost:8000/api/ml/train

# 5. Статистические тесты
curl -X POST http://localhost:8000/api/tests/run

# 6. Генерация отчёта
curl -X POST http://localhost:8000/api/report/generate

# 7. LLM-анализ
curl -X POST http://localhost:8000/api/llm/analyze \
  -H "Content-Type: application/json" \
  -d '{"question": "Какие ключевые слова имеют наибольший потенциал?"}'
```

### 3. Предсказание изменения позиции

```bash
curl -X POST http://localhost:8000/api/ml/predict \
  -H "Content-Type: application/json" \
  -d '{
    "motiv": 5.0,
    "position": 30.0,
    "organic_us": 100.0,
    "activation_us": 50.0,
    "month": 8,
    "quarter": 3,
    "day_of_week": 3,
    "is_weekend": 0,
    "keyword": "sound amplifier"
  }'
```

## 🤖 LLM-интеграция

### Методология ASO

LLM обучен на методологии ASO, которая включает:

- 12 правил продвижения (R1–R12)
- 5 сценариев работы с мотивом
- 12 кластеров ключевых слов
- принципы анализа данных и их интерпретации

### Системные промпты

LLM работает в трёх ролях:

- **Analyst** — анализ данных и интерпретация
- **Plots** — объяснение графиков
- **Recommendations** — генерация рекомендаций

### Примеры запросов к LLM

```python
# Анализ данных
POST /api/llm/analyze
{"question": "Какие ключевые слова имеют наибольший потенциал?"}

# Генерация стратегии
POST /api/llm/strategy
{}

# Объяснение графика
POST /api/llm/explain_plot
{
  "plot_name": "eda_overview.png",
  "description": "Общий обзор EDA",
  "context": "Данные за 2023–2026"
}

# Свободный диалог
POST /api/llm/chat
{"message": "Что делать при падении позиций?"}
```

## 📊 Методология ASO

### Правила продвижения (R1–R12)

| Правило | Название               | Описание                              |
|---------|-------------------------|-----------------------------------------|
| R1      | Базовый цикл            | M = 1 → 1 → 0                          |
| R2      | Оценка динамики         | Рост = улучшение на 1+ позиций         |
| R3      | Увеличение мотива       | При росте более 10 позиций             |
| R4      | Пропуск при падении     | Минимум 1 день пропуска                |
| R5      | Ограничение мотива      | Для новых запросов ≤ 2                 |
| R6      | Целевые позиции         | По частотности ключей                  |
| R7      | Максимум 3 цикла        | С мотивом 2                            |
| R8      | Повышение до 3          | При росте 50%                          |
| R9      | Процентный шаг          | 15% (1–14) или 10% (15+)               |
| R10     | Откат −30%              | При отсутствии роста                   |
| R11     | Поддержка               | Снижение на 2–3 единицы                |
| R12     | Максимальный мотив      | 30% от трафика                         |

### Кластеры ключевых слов

| Категория позиции | Категория мотива | Название кластера   |
|---------------------|--------------------|-----------------------|
| top10 (≤ 10)        | high               | top10_high            |
| top10 (≤ 10)        | medium             | top10_medium           |
| top10 (≤ 10)        | low                | top10_low              |
| top10 (≤ 10)        | zero               | top10_zero             |
| top50 (≤ 50)        | high               | top50_high             |
| top50 (≤ 50)        | medium             | top50_medium            |
| top50 (≤ 50)        | low                | top50_low               |
| top50 (≤ 50)        | zero               | top50_zero              |
| above50 (> 50)      | high               | above50_high            |
| above50 (> 50)      | medium             | above50_medium          |
| above50 (> 50)      | low                | above50_low             |
| above50 (> 50)      | zero               | above50_zero            |
